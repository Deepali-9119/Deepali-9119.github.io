## 🚀 Local Development & Preview

This portfolio uses a modern, zero-dependency, ultra-fast web architecture:

```bash
# 1. Navigate to the project directory
cd /Users/sogo/.gemini/antigravity/scratch/deepali-portfolio

# 2. Start a local HTTP server
python3 -m http.server 8080

# 3. Open in your browser
open http://localhost:8080
```

### Deployment
Can be deployed instantly to:
- **GitHub Pages**: Push repo to GitHub and enable Pages in repository settings.
- **Vercel / Netlify / Cloudflare Pages**: Connect the repository or run `npx vercel` / `npx netlify deploy`.
